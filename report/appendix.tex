\section{Running the Application}
\begin{enumerate}[leftmargin=*]
\item Install Python 3.10 or newer (and Node.js if the website should be rebuilt).
\item In the project folder run \texttt{./run.sh} (macOS/Linux) or \texttt{run.bat} (Windows). It installs the Python packages, builds the website and starts the server.
\item Open \url{http://localhost:8000}. Stop the server with Ctrl+C.
\item Tests: \texttt{python -m pytest}. Experiments: \texttt{python experiments/run\_experiments.py}.
\item Without Python, \texttt{web/dist/index.html} opens the website on saved results.
\item Source code: \url{https://github.com/namansingla-glitch/lightpath-cloud-task-placement}. Main folders: \texttt{cloudplace/} (algorithms), \texttt{api/} (server), \texttt{web/} (website), \texttt{experiments/}, \texttt{tests/}, \texttt{report/}, \texttt{presentation/}.
\end{enumerate}
